\begin{abstract}
Expressive text for VR comedy must select useful content without missing its delivery window. This project implements a backend that separates incremental caption proposals from bounded commitment, retains candidates across subsequent ASR updates, and validates them against observed ASR updates. After component profiling and development, the method is frozen and evaluated on 32 new authored positive utterances and eight ordinary negatives using 532 measured GPU request records. In paired backend replay, timely target coverage increases from 7/32 for sentence-final generation to 13/32 for cached commitment. Fixed-interval streaming reaches 14/32; caching trades one timely case and additional confirmation delay for 25.9\% fewer requests, 26.4\% lower replayed service demand, and 62.1\% fewer text changes. A separate controlled overload test increases fresh-supported output from 124/287 to 165/287 while reducing demand by 39.0\%. These results establish specific prototype and scheduling improvements, with remaining selection and reveal-timing failures reported. GPU service is measured on an RTX 4090; transcript arrivals and commitment clocks are simulated. Physical headset latency and audience experience remain unmeasured.
\end{abstract}
