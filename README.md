# VRStandup report draft

Editable draft for review and collaboration. `draft.pdf` is the reviewed nine-page version: eight main-text pages and one reference page.

## Compile in Overleaf

1. Import this repository from GitHub using your available Overleaf integration, or upload a ZIP of this directory with its folder structure intact.
2. Set the main document to `main.tex` and the compiler to **XeLaTeX**.
3. Recompile. Keep `IEEEtran.cls`, the supporting `.tex` files, and all six PDFs under `figures/` together.

The report distinguishes measured RTX 4090 GPU service from simulated transcript arrivals and backend display replay. Physical VR display latency remains unmeasured. On the authored positive holdout, cached commitment reaches 13/32 timely targets versus 7/32 for sentence-final generation and 14/32 for fixed streaming, trading one fixed-streaming success for less work and fewer text changes.

`SHA256SUMS` records the prepared draft files for verification.
